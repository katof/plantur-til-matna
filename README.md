# Plantur til matna

Royndarútgáva av temasíðu til undirvísing við støði í *Plantur til matna*
eftir Siggu Rasmussen. Bókarverkætlanin er eitt samstarv millum høvundin,
Nám og Búnaðarstovuna.

Síðan hevur níggju undirvísingaruppskot, plantulistar úr sBókini,
leiting og prentklár uppgávubløð. Undirvísingaruppskotini eru nýskrivað
við støði í bókini.

Sniðið er lagt sum ein nútímans lærusíða: føst leiðarlinja ovast við
virknum parti, yvirlit yvir uppgávubløðini, framgongd pr. deild
(„Merk sum gjørt“ verður goymt í kagaranum) og eitt rólig kortsnið,
sum virkar á telefon, teldu og í prenti.

## GitHub Pages

Set **Settings → Pages → Deploy from a branch → main → / (root)**.
Síðan er ein vanlig HTML-fíla og krevur onga bygging ella innlegging av pakkum.

## Tilfar og keldur

- [sBókin Plantur til matna](https://planturtilmatna.sbok.nam.fo/)
- Myndir verða heintaðar frá almennu myndaslóðunum hjá Snar.
- Kelduleinkjur og bókarstøð standa á síðuni.

Pappírsbókin og fulla PDF-útgávan eru ikki í hesum savninum.
Ein fyribils noindex-merking er sett á síðuna.
